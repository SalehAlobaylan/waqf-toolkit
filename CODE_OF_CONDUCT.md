# Code of Conduct

## Our standard

The goal of this project is useful, trustworthy tools. To get there, interactions in this repository — issues, pull requests, discussions, reviews — should be:

- **Respectful.** Disagree about code and ideas freely; do not make it personal.
- **Honest.** Do not overstate your contribution, the state of a feature, or your expertise — especially on sensitive religious-calculation topics.
- **Patient with newcomers.** "Good first issue" exists for a reason. Answer questions you once asked.

Unacceptable behavior includes harassment, hate speech, trolling, publishing others' private information, sexualized language or imagery, and sustained disruption of project discussions.

## Scope

This applies within project spaces (issues, PRs, discussions) and when representing the project publicly.

## Enforcement

Maintainers may remove, edit, or reject contributions that violate this code, and may temporarily or permanently ban contributors for serious or repeated violations. Decisions can be appealed by contacting the maintainers privately.

Reports: open a private contact via GitHub ([@SalehAlobaylan](https://github.com/SalehAlobaylan)) or email the address listed on that profile.

Maintainers are also bound by this code. Violations by maintainers should be reported the same way and will be taken seriously.
